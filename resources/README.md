# Données publiques téléchargeables

`grammalecte/` contient les dictionnaires et données grammaticales. `camembert/` contient les métadonnées publiques CamemBERTv2, son vocabulaire, ses notices et le dictionnaire morphologique utilisé par le correcteur. Ce dernier sert à reconnaître les mots et leurs flexions ; il ne contient pas les définitions, antonymes ou rimes consultables. Les licences et provenances de ces données restent à conserver avec les packs.

Le JavaScript de Grammalecte est conservé séparément dans `plugin/vendor/grammalecte/` et intégré au plugin. Tous les binaires de préparation sont dans `scripts/` : les sources ONNX complètes, la source MLM et les tableaux de poids CamemBERTv2 dans `scripts/neural/camembert/`, l’ancien runtime inutilisé dans `scripts/neural/runtime.wasm`. Le pack neuronal distribue uniquement les tableaux de poids convertis `onnx/weights-0.bin` et `weights-1.bin`, avec les JSON et notices de ce dossier ; aucun code ni runtime n’est téléchargé.

La liste des fichiers effectivement distribués et les données partagées sont définies dans [linguistic-files.ts](../plugin/linguistic-files.ts). `npm run resources -- /chemin/de/destination` prépare les fichiers de téléchargement et leurs catalogues SHA-256 à partir de ce dossier et des poids conservés dans `scripts/neural/camembert/`. Les données supplémentaires de préparation ou de test restent dans `scripts/` et sont exclues des packs. Les noms des fichiers GitHub restent indépendants des chemins sources. Les téléchargements installés sont conservés dans `data/resources/<pack>/<empreinte>/` ; les anciennes installations sous `resources/<pack>/<empreinte>/` restent lisibles. La CI publie ces fichiers dans la préversion GitHub `resources-VERSION` correspondant au plugin ; la release stable ne contient que `main.js`, `manifest.json` et `styles.css`.

`synonymes/` contient la fusion publique de myThes français et WOLF, leurs provenances et leurs licences LGPL-2.1-or-later / CeCILL-C. Le pack téléchargeable contient le JSON fusionné et ses notices ; les originaux restent dans `scripts/synonymes/sources/` pour le reproduire. Voir [le format JSON et la conversion](../doc/synonymes.md).

`definitions/`, `antonymes/`, `phonetique/` et `rimes/` contiennent les packs publics Finition issus du Wiktionnaire francophone via Kaikki/Wiktextract, sous CC BY-SA 4.0. Chaque JSON inclut sa provenance et sa licence dans `license`, et chaque pack contient le texte intégral de la licence. Définitions et relations sont conservées par sens ; les rimes sont dérivées des transcriptions API. Les imports privés restent séparés dans `Antidote/dictionnaires/` et `data/`. Voir [les sources, limites et formats](../doc/dictionnaires.md).

Le code des moteurs reste intégré au plugin. Les modèles locaux ajoutés par l’utilisateur se trouvent dans `scripts/neural/models/` et les ressources privées dans le dossier ignoré par Git ; aucun de ces dossiers ne fait partie des packs publics. Voir [le format des modèles](../doc/neural-model.md).

CamemBERTv2 est préparé depuis `almanach/camembertv2-base` (révision `42096e44334c6d256ef099c5d8936f9e272a938f`) et son encodeur ONNX Community (`6feb53a77def2a26b1dcd49ec3b70799411a8ba6`). L’export communautaire ne contient pas la tête MLM : le préparateur restaure celle du checkpoint officiel, ainsi que les embeddings d’origine, et vérifie les empreintes SHA-256. Les projections internes restent quantifiées. Les fichiers v1 sont conservés dans `scripts/neural/camembert-v1/`, notamment pour préparer les modèles spécialisés utilisant l’ancien vocabulaire.
