# Données publiques téléchargeables

`grammalecte/` contient les dictionnaires et données grammaticales. `camembert/` contient les poids publics CamemBERT, son vocabulaire, ses notices et le dictionnaire morphologique utilisé par le correcteur. Ce dernier sert à reconnaître les mots et leurs flexions ; il ne contient pas les définitions, antonymes ou rimes consultables. Les licences et provenances de ces données restent à conserver avec les packs.

Le JavaScript de Grammalecte est conservé séparément dans `plugin/vendor/grammalecte/` et intégré au plugin. Les fichiers `camembert/onnx/model-0.bin` et `model-1.bin` sont les sources ONNX utilisées par les outils de conversion et de comparaison ; ils restent versionnés pour reproduire ces contrôles. Seuls les tableaux de poids convertis `onnx/weights-0.bin` et `weights-1.bin` sont distribués dans le pack neuronal. L’ancien fichier `runtime.wasm`, inutilisé, est conservé dans `helper/neural/runtime.wasm` et peut être versionné ; il n’est chargé ni par le plugin ni par les outils actuels et reste exclu des packs.

La liste des fichiers effectivement distribués et les données partagées sont définies dans [linguistic-files.ts](../plugin/linguistic-files.ts). `npm run resources -- /chemin/de/destination` prépare les fichiers de téléchargement et leurs catalogues SHA-256 à partir de ce dossier. Les données supplémentaires de préparation ou de test ne sont pas ajoutées automatiquement aux packs. La CI publie ces fichiers dans la préversion GitHub `resources-VERSION` correspondant au plugin ; la release stable ne contient que `main.js`, `manifest.json` et `styles.css`.

`synonymes/` contient la fusion publique de myThes français et WOLF, leurs originaux, leurs provenances et leurs licences LGPL-2.1-or-later / CeCILL-C. Le pack téléchargeable contient le JSON fusionné et ses notices ; les originaux restent dans le dépôt pour le reproduire. Voir [le format JSON et la conversion](../doc/synonymes.md).

`definitions/`, `antonymes/`, `phonetique/` et `rimes/` contiennent les packs publics Finition issus du Wiktionnaire francophone via Kaikki/Wiktextract, sous CC BY-SA 4.0. Chaque JSON inclut sa provenance et sa licence dans `license`, et chaque pack contient le texte intégral de la licence. Définitions et relations sont conservées par sens ; les rimes sont dérivées des transcriptions API. Les imports privés restent séparés dans `Antidote/dictionnaires/` et `data/`. Voir [les sources, limites et formats](../doc/dictionnaires.md).

Le code des moteurs reste intégré au plugin. Les modèles locaux ajoutés par l’utilisateur se trouvent dans `helper/neural/models/` et les ressources privées dans le dossier ignoré par Git ; aucun de ces dossiers ne fait partie des packs publics. Voir [le format des modèles](../doc/neural-model.md).
